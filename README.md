This is the repo for our NLP 245 Final Project of evaluating LLM's capability as therapists.

Our team consists of Camellia Bazargan, Yash Bhedaru, Yousuf Golding, Olivia Wang

Our project includes 2 components
first part is the classification task of stress v.s. trauma according to the subreddit data
second part is evaluation of the response generated by LLMs on metrics coherence, fluency, empathy, professionalism, reflection, education and conciseness
